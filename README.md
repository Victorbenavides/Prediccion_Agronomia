# Prediccion_Agronomia
Leemos datos complejos: Cargamos un archivo de Excel con información detallada, como temperatura del suelo y del aire, precipitación, humedad relativa, pH y hasta el uso de fertilizantes.Definimos el objetivo: Establecemos que nuestra variable a predecir ($y$) es la Humedad del Suelo (%), mientras que todas las demás variables climáticas son nuestras características de entrada ($X$).Dividimos para evaluar: Separamos los datos en un conjunto de entrenamiento (80%) y uno de prueba (20%) para asegurar que el modelo realmente aprenda y no solo memorice los datos.Entrenamos el modelo: Creamos y ajustamos un objeto de LinearRegression() para que encuentre la relación matemática entre el clima y la humedad.Evaluamos con precisión: Hacemos predicciones y calculamos el Error Cuadrático Medio (MSE) y el $R^2$. El coeficiente $R^2$ nos dirá qué tan bien explican nuestras variables climáticas los cambios en la humedad del suelo.Visualizamos los resultados: Generamos una gráfica de "Predicciones vs Valores Reales". La línea roja representa el escenario ideal donde la predicción es exacta, y los puntos azules nos muestran qué tan cerca (o lejos) se quedó nuestra IA de la realidad.
